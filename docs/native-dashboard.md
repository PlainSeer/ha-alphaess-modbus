# Native-card alternative (manual)

The static example in [examples/native_dashboard.json](../examples/native_dashboard.json) remains a manual alternative. **v1.19.3b4 uses the packaged dark dashboard by default**; see [installation and migration](managed-dashboard.md).

The static example does not auto-discover renamed or newly enabled entities. Keep it only if you intentionally want standard HA cards instead of the dark frontend. HACS installation does not overwrite arbitrary native dashboards.
